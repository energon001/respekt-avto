# Респект Авто — лендинг автосервиса

![Превью сайта](docs/preview.jpg)

Статический одностраничный сайт автосервиса «Респект Авто» (Челябинск).

**Публикация:** https://energon001.github.io/respekt-avto/

## Стек

- Чистый HTML + CSS + JavaScript, без сборки и зависимостей
- Шрифты: Unbounded (заголовки) + Manrope (текст), локальные woff2 с кириллицей
- Изображения: webp/jpg в 480/900/1600, `srcset` + `loading="lazy"`
- Форма записи отправляет сообщение в WhatsApp (`wa.me`), бэкенд не нужен
- Карта: iframe виджета Яндекс.Карт с меткой на СНТ Колющенец, 6-я улица, 274

## Структура

```
index.html        разметка всех 11 секций
css/style.css     тёмная тема, токены, адаптив (640 / 900 / 1200)
css/fonts.css     @font-face локальных шрифтов
js/main.js        таймер «открыто/закрыто», меню, карусель отзывов, reveal, маска телефона, форма
fonts/            woff2-подмножества Unbounded и Manrope
img/              фото цеха (webp + jpg), img/orig — исходники (в публикацию не входят)
```

## Деплой

```powershell
.\.work\publish.ps1
```

Скрипт копирует исходники в `.work/deploy`, коммитит и пушит в `main` — GitHub Pages пересобирает сайт автоматически (~1 минута).
